# 民用航空 CFD / 并行计算 / 流动传热仿真工程师成长路径（工作 1 年 ~ 3 年）

> 适用对象：工作约 1 年，民用航空方向，主攻 CFD、并行计算、流动传热仿真
> 目标：从"会跑流程的人"成长为"能定义问题、做技术判断的人"

---

## 一、总体成长主线

| 阶段 | 时间 | 核心目标 |
|------|------|----------|
| 第 1 年（已度过） | 入职 ~1 年 | 熟悉工具链、跑通标准流程、建立工程直觉 |
| 第 2 年 | 1 ~ 2 年 | 吃透求解器原理、掌握网格与误差控制、开始负责完整算例 |
| 第 3 年 | 2 ~ 3 年 | 形成领域专长（如气动/热管理/燃烧）、具备独立定义与验证模型的能力 |

## 二、需要系统学习的知识

### 1. 理论基础（持续补，不求一次学完）

- [ ] **计算流体力学理论**
  - 控制方程（NS 方程）的守恒形式与数学性质
  - 有限体积法（FVM）的离散思想：对流项格式（Upwind、TVD、WENO）、扩散项离散、源项处理
  - 湍流模型体系：RANS（k-ε 系列、k-ω SST、Spalart-Allmaras）、LES/DES 的适用边界与代价
  - 壁面函数、y+ 准则、网格收敛性（Grid Convergence Index, GCI）
- [ ] **流动与传热**
  - 对流换热机理、Nu/Re/Pr 关联式的物理含义
  - 共轭传热（CHT）的耦合收敛问题
  - 航空典型问题：机翼气动、发动机短舱冷却、电子设备舱热管理、防冰/除冰（icing）、压气机/涡轮叶片冷却
- [ ] **数值线性代数与并行计算**（你的差异化优势）
  - Krylov 子空间方法：CG、GMRES、BiCGStab
  - 预条件器：ILU、AMG（代数多重网格）、领域分解（DDM）
  - MPI 通信模式、负载均衡、并行效率度量（强/弱扩展性）
  - GPU 加速：CUDA 基础、混合 MPI+CUDA 编程
  - 若做求解器开发：C++（模板元编程、内存管理）、PETSc / Trilinos / OpenFOAM 源码
- [ ] **编程与工具语言**
  - Python（数据处理、自动化、后处理）：numpy / scipy / pandas / matplotlib
  - 二次开发：Fluent UDF/UPI 或 OpenFOAM 的 C++ 求解器层
  - Linux 环境：Shell 脚本、SLURM/PBS 作业调度、集群使用

### 2. 航空领域知识（决定你能走多远）

- [ ] **适航与验证体系**
  - 了解局方（CAAC / FAA / EASA）对仿真结果用于型号取证的验证要求（V&V：Verification & Validation）
  - 仿真不确定度量化（UQ）基本概念：误差来源分解、确认（validation）vs 校验（verification）
- [ ] **风洞试验基础**
  - 风洞试验原理、洞壁干扰、雷诺数效应、试验与 CFD 对标的流程与常见差异来源
  - 能看懂试验报告、参与一次完整的"试验对标—模型修正"闭环（极其加分）
- [ ] **飞机总体与系统设计常识**
  - 基本构型、飞行包线、设计工况（巡航、起飞、爬升、结冰）
  - 了解 CFD 结果如何被下游（性能、载荷、强度）使用——仿真不是目的，输入到设计链才是

## 三、需要动手做的实践

### 1. 标准算例与验证练习（第 2 年重点）

- [ ] **经典验证算例**（自己动手算一遍，不要只跑默认设置）
  - 二维翼型（NACA 0012 / RAE 2822）：网格收敛性研究 + 与实验压力分布对标
  - 后台阶流动 / 圆柱绕流：对比不同湍流模型与实验
  - 方腔自然对流 / 圆管强制对流：传热关联式对标
- [ ] 每个算例输出一份**小型 V&V 报告**：网格收敛指数、不确定度估计、与实验的偏差分析

### 2. 并行计算专项（做出口碑）

- [ ] **并行效率实测项目**：选取一个中型算例，做 1 / 8 / 32 / 128 / 512 核的强扩展与弱扩展测试，画出效率曲线并分析瓶颈（通信 / I/O / 负载均衡）
- [ ] **网格分区策略研究**：METIS / ParMETIS 分区，对比不同分区对收敛性和效率的影响
- [ ] 如有条件：**一个 GPU 移植或加速小项目**（哪怕只是把线性求解器的一段搬到 GPU），这是未来 5 年的硬通货
- [ ] 向团队输出：并行计算最佳实践文档 + 一个自动化提交/监控作业的脚本工具

### 3. 完整型号级项目（第 2~3 年）

- [ ] 独立负责一个型号级算例的全流程：几何清理 → 网格（含收敛性）→ 求解设置 → 收敛监控 → 后处理 → 报告
- [ ] 重点训练**结果可信度判断**：异常流动结构是物理还是数值？网格加密后结论变不变？和其他工程师的独立计算互查（code-to-code comparison）

### 4. 仿真-试验对标闭环（最有价值的一次实践）

- [ ] 争取参与一次真实的试验对标：提前做试验前预测（blind prediction）→ 拿到试验数据 → 分析偏差来源（网格？湍流模型？边界条件？试验本身？）→ 修正模型
- [ ] 产出：一篇对标技术报告，含定量偏差分析（如升力系数偏差 < 5% 的达成路径）

### 5. 自动化与工具建设（团队贡献）

- [ ] 用 Python 搭建一个**前处理/后处理自动化流水线**（几何清理脚本、批处理提交、自动出图出报告）
- [ ] 在内部推广，让同事受益——工具能力是最容易"被看见"的贡献

## 四、软技能与职业发展

- [ ] **表达能力**：每季度做一次技术分享（内部分享会即可），练习把复杂技术讲清楚
- [ ] **报告写作**：学习适航符合性报告/技术报告的写法，结论先行、数据支撑
- [ ] **跨部门协作**：主动和强度、性能、试验部门交流，理解他们怎么用你的结果
- [ ] 1 年后与主管做一次**职业规划面谈**：明确走技术专家路线还是技术管理路线，索取具体项目机会

## 五、分年里程碑 Checklist

### 工作第 2 年结束时应做到：

- [ ] 独立完成型号级 CFD 算例全流程，无需他人兜底
- [ ] 完成至少 3 个经典验证算例并产出 V&V 小报告
- [ ] 完成一次并行扩展性实测并输出分析报告
- [ ] 掌握至少一种湍流模型的理论推导级理解（如 SST k-ω）
- [ ] 搭建一套个人/团队的自动化脚本工具
- [ ] Python 能写千行级数据处理/自动化代码

### 工作第 3 年结束时应做到：

- [ ] 主导一次完整的仿真-试验对标闭环
- [ ] 在某一航空子领域（气动/热管理/防冰等）成为组内"问到他"的人
- [ ] 具备给年轻同事 review 算例设置、指出数值问题的能力
- [ ] 有 1~2 项可展示的团队级成果（工具、流程、报告或专利/论文）
- [ ] 明确中期方向：求解器开发 / 工程应用专家 / 仿真体系与 V&V

## 六、结合 AI 趋势的建议（写给 2026 年的你）

- [ ] **不要让"跑流程"成为你的标签**——AI 最先吃掉的就是画网格、出报告、跑参数扫描；把精力放在误差控制、结果判断、试验对标上
- [ ] **AI 工具纳入日常**：用 LLM 写/改 UDF 和脚本、辅助读求解器文档、自动化后处理；效率是你的竞争力
- [ ] **并行计算 + GPU 是你的护城河**：CAE 的 AI 化（代理模型、AI 求解器）反而放大对高性能计算人才的需求，懂物理又懂并行的人稀缺
- [ ] **守住"验证"这个高地**：AI 产生的仿真初稿需要人背书，未来"为 AI 仿真结果做验证与签发"会成为新的核心岗位

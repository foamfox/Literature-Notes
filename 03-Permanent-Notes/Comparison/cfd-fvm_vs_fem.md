# 有限体积法（FVM） vs. 有限元法（FEM）

> **类型**: 比较笔记
> **比较对象**: [[有限体积法（FVM）]] vs [[有限元法（FEM）]]
> **比较维度**: method
> **来源**: 经典教材与工程实践总结

---

## 1. 比较概览

### 为什么要比较这两个东西？
在计算力学与计算物理领域，FVM 与 FEM 是两种最主流的偏微分方程离散框架。选择哪一种方法，直接决定了：网格生成策略、边界条件实现方式、守恒性保证机制、高阶扩展路径、以及代码架构。对于从事 CFD、固体力学或多物理场耦合的工程师与研究者，理解二者的本质差异是方法选型的前提。

### 一句话结论
> FVM 以**局部守恒**为核心，通过**通量重构**在控制体上严格保证物理量的收支平衡，天然适合对流主导问题；FEM 以**变分原理**为核心，通过**基函数投影**在全局能量意义下寻求最优逼近，天然适合扩散/椭圆型问题与复杂几何。
> 一句话，**FVM胜在“物理”**（守恒、间断、波的传播）；**FEM胜在“数学”**（变分、几何适应性、多物理场统一）。

## 2. 多维度对比表

| 对比维度        | FVM                                              | FEM                                                         |
| ----------- | ------------------------------------------------ | ----------------------------------------------------------- |
| **核心定义**    | 将求解域划分为控制体，对每个控制体积分守恒方程，通过面通量实现离散                | 将求解域划分为单元，对微分方程乘试探函数后积分（弱形式），通过基函数插值离散                      |
| **数学框架**    | 积分守恒律 + 通量重构（Gauss 定理）                           | Galerkin 变分原理 + Sobolev 空间投影                                |
| **未知量**     | 单元平均值（cell-centered）或节点值（node-centered）          | 节点自由度（位移、温度、压力等）                                            |
| **适用前提/假设** | 控制体上的积分守恒必须成立；通量计算需要相邻单元信息                       | 解属于适当的 Sobolev 空间；分部积分后边界条件可自然出现                            |
| **守恒性**     | **局部严格守恒**（每个控制体的净通量 = 源项）                       | **全局弱守恒**（仅在积分/变分意义下守恒）                                     |
| **几何适应性**   | 中。非结构 FVM 可用四面体/多面体，但通量计算对网格正交性、skewness 敏感      | **强**。等参映射（isoparametric mapping）将任意曲边单元映射到标准单元，几何协调性好      |
| **网格质量敏感度** | 高。面心连线与法向的偏差、非正交性、长宽比直接影响梯度重构与通量精度               | 中。弱形式降低了对解光滑性的要求，扭曲单元可通过 Jacobian 映射在参考单元上统一处理              |
| **边界条件处理**  | Dirichlet：Ghost cell 外推或直接面通量赋值；Neumann：直接计算边界通量 | Dirichlet：直接约束节点自由度（本质边界）；Neumann：自然出现在弱形式边界积分中             |
| **间断/激波处理** | **天然优势**。Riemann 求解器、TVD、WENO 等格式可直接嵌入通量计算       | 困难。标准连续 FEM 在间断处产生 Gibbs 现象；需 DG、SUPG、Shock-capturing 等特殊处理 |
| **高阶扩展**    | 通过高阶通量重构（MUSCL、WENO、DG）或边界高斯积分点实现                | 通过提高形函数阶数（p-refinement）或高阶等参单元实现，路径更系统                      |
| **精度/收敛性**  | 二阶为主流，高阶（>3）实现复杂但已有成熟路径（DG/FR/WENO）              | 二阶为主流，高阶（谱元、hp-FEM）实现系统且理论成熟                                |
| **计算成本**    | 相同网格与阶数下，FVM 通常内存占用更低（无需全局刚度矩阵组装），但迭代步数可能更多      | 需要组装全局刚度矩阵并求解大规模稀疏线性系统，内存开销大，但收敛特性通常更稳定                     |
| **实现难度**    | 中。核心难点在于通量计算、梯度重构、非正交修正、湍流模型耦合                   | 中。核心难点在于刚度矩阵组装、数值积分、边界约束处理、高阶形函数构造                          |
| **并行扩展性**   | **强**。单元间耦合仅通过面通量，通信模式简单，适合大规模分布式并行              | 中。全局刚度矩阵组装需通信，但矩阵结构规则，预处理与求解器成熟                             |
| **典型应用场景**  | 可压缩外流（航空、航天）、多相流、燃烧、环境流体力学                       | 固体力学、结构动力学、传热、电磁场、地球物理、生物力学                                 |
| **代表软件**    | Fluent, CFX, OpenFOAM, STAR-CCM+, SU2, FUN3D     | Abaqus, Nastran, ANSYS Mechanical, FEniCS, deal.II, COMSOL  |

## 3. 差异本质分析

### 核心差异点

1. **守恒律的实现层级不同**
   - FVM 的守恒是**逐单元、逐时间步**的硬约束：每个控制体的净通量必须严格等于该控制体内物理量的变化率。这是通过 Gauss 定理将体积分转化为面积分后直接实现的。
   - FEM 的守恒是**全局、弱形式**的：分部积分后，边界通量项与内部积分项在整体加权残差中平衡。单个单元内部并不保证局部守恒（连续 FEM），只有在全域积分意义下才满足守恒。

2. **解的表示与单元间连续性**
   - FVM 的单元平均值在单元间**允许间断**，因此天然适合引入 Riemann 求解器处理对流间断。
   - FEM 的标准连续单元（$C^0$）在单元间**强制连续**，解的间断必须通过特殊的间断 Galerkin（DG）或 enriched FEM 才能刻画。

3. **几何与离散的关系**
   - FVM 直接操作**物理网格**的几何量（面法向、面积、单元中心距），复杂几何的逼近误差直接传递到通量计算中。
   - FEM 通过**等参映射**将物理单元映射到标准参考单元，复杂几何的误差被封装在 Jacobian 中，与离散格式解耦。

### 容易混淆的相似点

- **两者都使用网格**：但 FVM 的核心对象是"控制体"（体积/面积），FEM 的核心对象是"单元"（节点/边/面）。
- **两者都涉及数值积分**：FVM 在面上积分通量（中点法则/高斯积分），FEM 在单元内积分弱形式（高斯积分）。但 FEM 的积分在**参考单元**上进行，与几何形状解耦；FVM 的积分直接在**物理面**上进行。
- **两者都可处理非结构网格**：但 FVM 在非结构网格上的梯度重构和通量计算需要额外的非正交修正；FEM 在非结构网格上的处理更为统一。
- **两者都有高阶版本**：FVM 的高阶依赖通量重构（WENO、MUSCL）；FEM 的高阶依赖形函数升阶（p-FEM、谱元）。

### 边界/过渡情况

- **在什么条件下二者等价？**
  - 对于**线性扩散方程**（Poisson 方程）在**结构化网格**上，二阶 FVM 与二阶 FEM（线性三角形/四边形）在数学上是等价的，离散方程几乎一致。
  - **间断 Galerkin（DG）方法**是二者的交汇点：它保留了 FEM 的变分框架和基函数投影，同时通过数值通量（Riemann 求解器）实现了单元间的局部守恒，兼具 FVM 的守恒特性与 FEM 的几何灵活性。
  - **有限体积法与有限元法的混合（FVM-FEM coupling）**：在流固耦合（FSI）中，流体域常用 FVM，固体域常用 FEM，通过界面通量/位移插值实现耦合。

## 4. 决策框架

### 选择指南

| 你的需求/约束                      | 推荐选择                        | 原因                                             |
| ---------------------------- | --------------------------- | ---------------------------------------------- |
| 求解可压缩 Euler / N-S 方程，含激波/强间断 | **FVM**                     | 局部守恒 + Riemann 求解器对间断的捕捉能力无可替代                 |
| 求解不可压 N-S 方程，关注压力-速度耦合       | **FVM** 或 **FEM**           | FVM 有 SIMPLE/PISO 等成熟算法；FEM 有稳定化方法（SUPG, PSPG） |
| 求解固体力学、结构动力学、传热、电磁           | **FEM**                     | 变分原理与材料本构、能量泛函天然契合；复杂几何适应性强                    |
| 复杂几何（强曲壁面、多孔介质、生物组织）         | **FEM**                     | 等参映射 + 非结构网格 + 局部加密，几何逼近精度高                    |
| 需要严格保证局部质量/能量/动量守恒           | **FVM**                     | 每个控制体的收支平衡是 FVM 的构造性保证                         |
| 需要高阶精度（>3阶）且几何复杂             | **FEM（谱元/hp-FEM）** 或 **DG** | 高阶形函数路径系统；DG 兼具 FVM 守恒优势                       |
| 大规模并行（百万~十亿网格）               | **FVM**                     | 通信模式简单，负载均衡易实现，OpenFOAM/SU2 等已验证               |
| 多物理场耦合（流-固-热-电）              | **FEM** 或 **混合**            | FEM 统一框架易于处理多物理场弱耦合；商用软件（COMSOL）基于此            |
| 快速原型验证，代码简洁                  | **FVM（结构网格）**               | 逻辑简单，易于手写实现                                    |

### 组合使用的可能性

- **流固耦合（FSI）**：流体域用 FVM（OpenFOAM/Fluent），固体域用 FEM（Abaqus/ANSYS），通过界面位移与力的传递实现耦合。这是工业界最成熟的组合。
- **DG 方法**：作为 FVM 与 FEM 的"杂交"，在流体（尤其高阶可压缩，波传播主导的流动）中越来越主流。它用 FEM 的基函数做单元内表示，用 FVM 的数值通量做单元间耦合。
- **FVM-FEM 混合离散**：在某些多物理场问题中，同一求解域内对不同方程采用不同离散（如对流项用 FVM，扩散项用 FEM），但实现复杂，非主流。

# Fabless vs Foundry vs IDM：半导体三种主流商业模式

> **类型**: 比较笔记
> **比较对象**: [[Fabless]] vs [[Foundry]] vs [[IDM]]
> **比较维度**: concept（商业模式与产业链分工）
> **来源**: 用户提供的知乎专栏文章；HKEXnews 招股书行业概览；EUR-Lex；Counterpoint Research

---

## 1. 比较概览

### 为什么要比较这三者？
> 半导体产业链按"设计—制造—封测"环节划分，一家企业覆盖哪些环节决定了它的资产结构、成本模型、风险敞口与竞争壁垒。无论是判断一家芯片公司的财报特征、评估供应链风险（如制裁下的产能保障），还是理解"轻资产 vs 重资产"之争，都需要先分清这三种模式。

### 一句话结论
> 三者本质上是**同一产业链上不同环节的分工方式**：Fabless 只做设计与销售，Foundry 只做制造，IDM 则设计、制造、封测全覆盖。

## 2. 多维度对比表

| 对比维度 | Fabless（无晶圆厂设计） | Foundry（晶圆代工厂） | IDM（垂直整合制造商） |
|----------|------------------------|----------------------|----------------------|
| 核心定义 | 仅从事芯片设计与销售，不自建晶圆厂，制造外包给代工厂 | 仅从事芯片制造（代工），不设计、不销售自有品牌芯片 | 设计、制造（自有产线）、封测全覆盖，垂直一体化 |
| 覆盖环节 | 设计 + 销售（封测多外包给 OSAT） | 制造（先进纯代工 Foundry 不做设计） | 设计 + 制造 + 封装测试 |
| 资本投入 | 低，轻资产 | 极高（晶圆厂单座投资可达百亿美元级） | 最高（全链条固定资产 + 持续折旧） |
| 核心能力/壁垒 | 架构与电路创新、快速产品迭代 | 制程工艺研发、良率与产能管理 | 设计与工艺协同优化（DTCO）、产能自控 |
| 优势 | 资本效率高、灵活性高、市场响应快、可聚焦研发 | 规模效应分摊巨额设备与研发成本，服务多客户摊薄风险 | 全流程可控、产能与供应链有保障、适合高可靠/长生命周期产品 |
| 劣势 | 依赖外部产能，供应保障、交期、工艺定制能力弱 | 自身不掌握产品定义，受下游景气周期影响大 | 固定资产重、折旧负担大、运营复杂、行业低谷亏损风险高 |
| 典型代表 | 高通、英伟达、联发科、华为海思、苹果（自研芯片）、AMD | 台积电、联电、中芯国际、GlobalFoundries、华虹 | 英特尔、三星（存储+代工双线）、美光、英飞凌、华润微 |
| 市场格局参考 | 设计公司数量最多，是当前主流创业模式 | 高度集中：2025Q4 台积电占全球纯代工市场约 72%，三星约 7%，中芯国际约 5% | 集中于存储、功率半导体等重协同领域 |

> 注：三星兼具 IDM 与 Foundry 双重身份——既自研自产存储/逻辑芯片，也对外提供代工服务（其代工份额计入 Foundry 统计口径）。

## 3. 差异本质分析

### 核心差异点
1. **对"制造环节"的取舍是分水岭**：Fabless 把制造外包以换取轻资产与敏捷性；IDM 自建产线以换取控制力与协同性；Foundry 则把制造本身做成了标准化服务。
2. **成本结构相反**：Fabless 的成本以研发费用为主、变动成本低；IDM/Foundry 的成本以固定资产折旧为主、固定成本高，必须靠规模摊薄——这决定了只有巨头才能玩得起 IDM。
3. **风险敞口不同**：Fabless 的软肋在供应链（产能、交期、地缘政治）；IDM 的软肋在重资产的周期波动。

### 容易混淆的相似点
- **Fabless vs Foundry 是共生关系而非竞争关系**：Foundry 是 Fabless 的"代工厂"，二者同属"垂直分工"模式，共享轻资产/专业化带来的效率。
- **IDM vs Foundry 都有晶圆厂**：外表相似，但 IDM 的产线服务于自有产品，Foundry 的产线服务于客户产品。
- **Foundry 可能承接 IDM 的外包订单**：部分 IDM 会将部分产能需求交给 Foundry，二者并非绝对隔离。

### 边界/过渡情况
> 三种模式之间存在连续的过渡形态：
> - **Fab-lite（轻晶圆厂）**：IDM 保留核心工艺、外包标准制造，如 AMD 2009 年出售晶圆厂后转向 Fabless。
> - **Virtual IDM（虚拟 IDM）**：Fabless 与代工厂深度绑定、联合开发专属工艺（如部分功率半导体公司），介于 Fabless 与 IDM 之间。
> - **混合模式**：保留核心环节 + 外包标准环节，正成为功率半导体等行业的转型方向。
> - 存储行业（DRAM/NAND）因设计与工艺需深度协同，长期以 IDM 为主，Fabless 仅与少数代工厂深度绑定。

## 4. 决策框架

### 选择指南
| 你的需求/约束 | 推荐选择 | 原因 |
|---------------|----------|------|
| 初创/中小团队，资金有限，追求快速迭代 | Fabless | 无需巨额固定资产投入，可租用 Foundry 先进制程 |
| 掌握核心 IP 但无制造能力（如 AI 芯片） | Fabless + 先进 Foundry | 先进制程自建几乎不可行，台积电 3nm/2nm 等先进节点仅 Foundry 可提供 |
| 需要全流程工艺-设计协同（如存储、功率器件） | IDM | 设计与制造的深度耦合是产品竞争力的来源 |
| 供应链安全敏感（受制裁/出口管制风险） | 向 IDM 或 Virtual IDM 演进 | 自有产能可抵御断供风险（如华为转向自建制造能力） |
| 已有产线但产品线多元 | 混合模式 / Fab-lite | 平衡资产效率与技术自主 |

### 组合使用的可能性
> 三种模式在现实中常组合出现：Fabless + Foundry + OSAT 构成"垂直分工"铁三角；IDM 也会向 Foundry 释放闲置产能（如三星、英特尔代工业务）；Fabless 可与 Foundry 联合开发专属工艺形成"准 IDM"能力。行业趋势并非单一模式胜出，而是分工精细化与协同深化并存。

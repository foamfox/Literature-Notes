# 固体域有限元网格 vs 流体域非结构化网格

> **类型**: 比较笔记
> **比较对象**: [[固体域有限元网格]] vs [[流体域非结构化网格]]
> **比较维度**: 概念 / 方法 / 代码（文件格式）
> **来源**: MSC Nastran 文档实践、有限元/CFD 通用规范

---

## 1. 比较概览

### 为什么要比较这两个东西？
在自研多物理场求解器或开发通用网格导入模块时，需要判断：
1. 同一份非结构化网格（节点+单元拓扑）能否同时服务于结构 FEM 和流体 CFD？
2. 如果格式可以互通，物理语义（材料、边界条件、自由度）如何映射？
3. 选择哪种中立格式（CGNS、VTK、Gmsh）能最大限度减少重复工作？

### 一句话结论
> **两者在底层数据结构（节点坐标+单元拓扑）上完全同构，差异仅在“单元之上”的物理语义层：FEM 以材料属性与节点自由度组织模型，CFD 以区域分区与边界面的物理标记组织模型。**

## 2. 多维度对比表

| 对比维度 | 固体域有限元网格 (FEM) | 流体域非结构化网格 (CFD) |
|:---|:---|:---|
| **核心定义** | 离散化连续固体介质，以单元刚度组装全局方程，求解位移/应力/应变 | 离散化流体域，在控制体/节点上求解 NS 方程，求解速度/压力/温度 |
| **底层数据结构** | 节点 (`GRID`) + 单元拓扑 (`CQUAD4`, `CHEXA`, `CTETRA`) | 节点 (`NODE`) + 单元拓扑 (`quad`, `hexa`, `tetra`) |
| **单元分组逻辑** | 按 **Property Set** 分组：`PSHELL`（壳厚）、`PSOLID`（实体）、`PCOMP`（铺层） | 按 **Zone / Region** 分组：`fluid`, `solid`, `porous`，并标记边界类型 |
| **物理量与自由度** | 节点具有 **DOF**：平动 (3)、转动 (3)；材料属性：E, ν, ρ, α | 节点无 DOF 概念，存储 **物理场变量**：u, v, w, p, T；流体属性：ρ, μ, cp |
| **边界条件挂载对象** | 直接挂在 **节点或单元** 上：`SPC`（约束）、`FORCE`（集中力）、`PLOAD`（面压） | 必须挂在 **面 (Face) 或边 (Edge)** 上：`wall`（壁面）、`inlet`（入口）、`outlet`（出口）、`symmetry` |
| **边界层/近壁处理** | 一般不要求特殊网格加密，关注单元 Jacobian 正定性 | **必须生成边界层棱柱层 (prism layer)**，要求第一层高度 y+ 可控，长宽比极大 |
| **单元阶次偏好** | 一阶 / 二阶均可，二阶单元（`CQUAD8`, `CHEXA20`）在隐式分析中常见 | 几乎清一阶；二阶仅在高阶 DG/FR/谱元方法中使用 |
| **网格质量准则** | 防止剪切锁定、体积锁定；允许适度畸变（尤其隐式非线性） | 极度关注 **正交性、长宽比、偏斜度 (skewness)**；边界层区域需结构化/半结构化 |
| **典型文件格式** | `.bdf` (Nastran), `.inp` (Abaqus), `.cdb` (Ansys) | `.msh` / `.cas` (Fluent), `.su2`, `.foam` (OpenFOAM) |
| **通用中立格式** | CGNS, VTK/VTU, Gmsh `.msh` 可通吃两者，但需各自补充语义层 | 同上 |

## 3. 差异本质分析

### 核心差异点
1. **语义层分离**：FEM 的“属性”是材料力学属性（E, ν, thickness），CFD 的“属性”是区域物理标记（fluid zone, wall boundary tag）。同一份 `tetra` 单元拓扑，在 FEM 里需要知道它属于哪种材料；在 CFD 里需要知道它是否邻接壁面。
2. **边界条件维度不同**：FEM 的边界条件通常是 0D（节点力）或 2D（面压），可直接由单元面计算；CFD 的边界条件必须显式定义“哪些单元面构成物理边界”，因为流场求解需要在边界面上施加通量条件（无滑移、压力梯度、质量流量）。
3. **近壁网格哲学不同**：固体 FEM 把壁面视为几何边界，网格在壁面处终止；CFD 把壁面视为**物理边界层**，需要在壁面法向生成高度渐变的棱柱层以解析边界层速度梯度。

### 容易混淆的相似点
- **节点+拓扑同构**：两者都用节点坐标和节点编号列表定义单元，因此通用解析器（只读 `GRID` + `CTETRA`/`CHEXA`）可以共用。
- **非结构化四面体/六面体单元**：固体和流体都使用 `tetra`, `hexa`, `pyramid`, `wedge` 等单元类型，几何描述完全一致。

### 边界/过渡情况
- **流固耦合 (FSI)**：在交界面处，固体网格和流体网格**共享几何面但通常不共享节点**（非匹配网格）。此时需要插值算子（如 RBF、最近邻、投影）将流体壁面压力映射到固体面力，或将固体位移映射到流体网格动边界。
- **多孔介质/渗流**：当 CFD 引入多孔区域模型时，其单元分组逻辑（Zone）与 FEM 的材料属性分组（Property Set）开始趋同，但边界条件挂载方式仍保持 CFD 的面标记逻辑。

## 4. 决策框架

### 选择指南（自研求解器网格导入模块）

| 你的需求/约束 | 推荐选择 | 原因 |
|:---|:---|:---|
| 只需要几何+拓扑，不关心物理 | 直接解析 `.bdf` / `.msh` 的节点和单元部分 | 底层数据结构相同，解析器可复用 |
| 需要同时支持 FEM 和 CFD 后处理 | **VTK/VTU** 或 **CGNS** | 通用格式，Paravvis、VisIt 均支持，且保留单元/面标记 |
| 需要保留完整 FEM 材料+载荷信息 | **Nastran `.bdf`** 或 **Abaqus `.inp`** | 行业标准，材料、属性、边界条件卡片完整 |
| 需要保留完整 CFD 边界区域信息 | **Fluent `.msh`** / **CGNS** | 区域 (Zone) 和边界标记 (Face Label) 是原生支持的 |
| 做流固耦合，需要非匹配网格插值 | **CGNS** + 中间格式（如 MBC 库、preCICE） | CGNS 支持多区域、多网格块，且保留面标记便于插值 |

### 组合使用的可能性
> **可以结合，但需分层设计**：
> 1. **底层**：统一网格解析器，只提取节点坐标和单元拓扑（`GRID` + `CQUAD4`/`CTETRA`/`CHEXA`）。
> 2. **中间层**：FEM 端映射到 Property/Material/DOF；CFD 端映射到 Zone/Boundary Tag/Fluid Property。
> 3. **上层**：各自求解器读取自己的语义层，网格几何层完全复用。
> 
> 推荐以 **CGNS** 或 **Gmsh `.msh`（Physical Groups）** 作为中立交换格式，两者都允许在单元/面上同时挂载 FEM 和 CFD 所需的元数据。
